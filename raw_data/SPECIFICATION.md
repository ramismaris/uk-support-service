Что-то вроде ТЗ

Система приёма и обработки заявок для управляющей компании, пользовательская часть — внутри Max-бота, управление вынесено в мини-приложение внутри Max

Меню клиента:

«Подать заявку» → заполнение формы (поля заявки заполняет клиент) → после отправки автоматически создаётся тикет с номером → далее клиент может продолжать переписку по этому тикету с менеджером

«Мои заявки» → список всех заявок клиента с номером и текущим статусом (в работе / отклонена / закрыта)

«Аварийные службы» → текстовое сообщение

«Услуги УК» → текстовое сообщение

«Оплата ЖКХ» → текстовое сообщение со ссылкой на сайт оплаты

«Задать вопрос» → контакты и телефоны + возможность написать сообщение, которое также уходит в чат/тикет поддержки

Функционал менеджера (мини-приложение):

Просмотр списка всех поступивших заявок (тикетов) с их статусом и данными заявителя

Открытие конкретной заявки — просмотр содержания и данных клиента

Переписка с клиентом внутри тикета (чат по заявке)

Изменение статуса заявки (в работе / отклонена / закрыта и т.д.)

Функционал админа (мини-приложение):

Включает весь функционал менеджера, плюс:

Архив заявок — просмотр закрытых и отклонённых заявок, с историей переписки и поиском

База пользователей — список всех клиентов бота

Просмотр профиля пользователя — привязанные адреса, история его заявок

Управление контентом:
— редактирование приветственного сообщения (текст + фото)
— редактирование текстов разделов «Аварийные службы», «Услуги УК», «Оплата ЖКХ» (включая ссылку), контактов для «Задать вопрос»
— настройка стилизации бота/панели

Отдельно, вне основного ТЗ — способ распространения продукта:
— Модель «коробка»: готовый продукт передаётся клиенту, тот настраивает сам
— Модель «подряд»: настройку под клиента выполняют разработчики
